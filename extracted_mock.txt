Math

Math — Q1   [Easy · 60 pts]   Correct answer: B

4(2x − 3) = 35 − 7 = 28. Dividing by 4 gives (2x − 3) = 7. (No need to solve for x.)

Math — Q2   [Easy · 60 pts]   Correct answer: B

Combine like terms: 3x² − x² = 2x²; 5x − (−2x) = 7x; −7 − 4 = −11.

Math — Q3   [Easy · 60 pts]   Correct answer: C

450 × 0.36 = 162 grams.

Math — Q4   [Medium · 80 pts]   Correct answer: B

Multiply the second equation by 4: 24x − 4y = 28. Add to the first: 27x = 54 ⇒ x = 2. Then y = 6(2) − 7 = 5. Product xy = 2 × 5 = 10.

Math — Q5   [Medium · 80 pts]   Correct answer: B

Complete the square: (x − 4)² + (y + 3)² = 24 + 16 + 9 = 49. Radius r = √49 = 7.

Math — Q6   [Medium · 80 pts]   Correct answer: B

Factor numerator and denominator: 2(x − 2)(x + 2) / [(x − 2)(x − 3)]. The common factor (x − 2) cancels, creating a removable discontinuity at x = 2.

Math — Q7   [Medium · 80 pts]   Correct answer: B

Restricted condition: passed inspection (total = 360). From Batch Alpha: 144. Probability = 144 / 360 = 0.40.

Math — Q8   [Hard · 100 pts]   Correct answer: C

Setting the equations equal gives x² + kx + 13 = 2x − 3, so x² + (k − 2)x + 16 = 0. For exactly one real solution, the discriminant must equal 0: (k − 2)² − 4(1)(16) = 0, so (k − 2)² = 64, giving k − 2 = ±8. The positive value is k = 10.

Math — Q9   [Hard · 100 pts]   Correct answer: B

sin(A) = BC / AB = 3/5, a standard 3k–4k–5k triangle. Perimeter = 3k + 4k + 5k = 12k = 72 ⇒ k = 6. Side BC = 3k = 18.

Math — Q10   [Hard · 100 pts]   Correct answer: A

(1/2)^(t/24) = [(1/2)^(1/4)]^(t/6) = (1 − r)^(t/6). Thus 1 − r = (1/2)^(1/4) ⇒ r = 1 − (1/2)^(1/4).
